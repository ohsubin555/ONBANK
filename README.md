# ONBANK — 모의 인터넷뱅킹 서비스

실제 인터넷뱅킹을 참고해 만든 **모의(가상) 인터넷뱅킹 서비스**입니다.
고객은 계좌 개설·이체·예적금·대출을, 직원과 관리자는 회원·계좌 관리와 이상거래 모니터링을 할 수 있습니다.

## 담당 기능 (팀원 2)

### 1. 계좌 개설
- 입출금 계좌(ON 통장) 개설: 비밀번호 4자리 + 약관 동의 → 계좌번호 발급
- 계좌번호 `1002-XXX-XXXXXX` 형식, 중복이면 최대 5회까지 다시 생성
- 계좌 비밀번호는 BCrypt로 암호화해 저장
- 관리자 화면에서 호출하는 계좌 상태 변경 메서드 제공 (승인·반려·동결·해제·해지·비밀번호 잠금 해제)

### 2. 입출금 · 즉시이체
- 계좌 상태별 입출금 규칙 (예: 동결 계좌는 입금만 가능, 해지 계좌는 모두 불가)
- 1회 / 1일 이체 한도, 날짜가 바뀌면 당일 누적 이체액 초기화
- 계좌 비밀번호 오류 횟수 누적 → 한도에 도달하면 출금·이체 잠금
- 10만 원 초과 타인 이체는 OTP 인증 필요 (팀원 1의 OTP 모듈 연동)
- 받는 분 이름 확인(가림 처리, 예: `김*수`), 한글 금액 표시, 확인 단계 후 이체

### 3. 예약이체 · 정기이체
- 예약이체: 날짜·시각을 지정해 등록 → 스케줄러가 매분 실행 대상을 찾아 이체
- 정기이체: 매월 N일 자동 이체, 종료일 지정, 31일 선택 시 말일로 처리
- 등록 시점에 비밀번호·OTP를 검증하고, 실행 시점에는 잔액·한도·계좌 상태만 다시 확인
- 조회·취소(해지) 화면, 시연용 [지금 실행] 버튼

### 4. 즐겨찾기
- 자주 쓰는 계좌 등록·수정·삭제·순서 변경
- 이체 화면에서 내 계좌 / 상대 계좌 즐겨찾기, 최근 입금 계좌 선택

### 5. 자산관리 리포트
- 월별 입금·출금, 저축액, 대출 상환액 집계 (본인 계좌끼리의 이체는 제외)
- 팀원 3의 예적금·대출 데이터를 연동해 총자산·순자산 계산
- 외부 차트 라이브러리 없이 SVG(도넛)·CSS(막대)로 그래프 구현, "표로 보기" 제공

## 구현하며 고민한 점

### 동시 이체 시 잔액이 꼬이지 않게
같은 계좌로 동시에 이체 요청이 들어오면 잔액이 잘못 계산될 수 있습니다.
이체할 때 두 계좌 행을 **비관적 락**으로 잠그고, 교착 상태(deadlock)를 피하려고 **항상 계좌 ID가 작은 쪽부터** 잠그도록 순서를 정했습니다.

### 이체가 실패해도 비밀번호 오류 횟수는 남게
비밀번호가 틀리면 예외가 발생해 트랜잭션 전체가 롤백되는데, 그러면 오류 횟수 증가까지 함께 취소됩니다.
비밀번호 검증을 **별도 트랜잭션(`REQUIRES_NEW`)**으로 분리해서 이체는 실패해도 오류 횟수는 저장되도록 했습니다.
같은 클래스 안에서 메서드를 호출하면 스프링 프록시를 거치지 않아 `REQUIRES_NEW`가 무시되므로, 검증 로직을 별도 Bean(`AccountPasswordVerifier`)으로 분리했습니다.

### 예약이체 실패 기록이 사라지지 않게
예약이체를 실행하다 실패하면 이체 트랜잭션은 롤백되어야 하지만, "실패했다"는 기록은 남아야 합니다.
실행기(Runner)에는 트랜잭션을 걸지 않고 **1건씩 따로 실행**한 뒤, 실패하면 **새 트랜잭션에서 실패 사유를 기록**하도록 나눴습니다.
한 건이 실패해도 다른 예약 건 실행에는 영향을 주지 않습니다.

### 다른 파트 조회가 실패해도 화면은 열리게
자산 리포트는 팀원 3의 대출·예적금 데이터를 함께 읽습니다.
처음에는 서비스 전체에 `@Transactional`을 걸었더니, 다른 파트 조회에서 예외가 나면 트랜잭션이 rollback-only 상태가 되어 리포트 저장까지 실패했습니다.
서비스에서 트랜잭션을 빼고 조회 실패를 경고 문구로 안내하도록 바꿔서, 해당 영역만 "불러오지 못했습니다"로 표시하고 나머지는 정상으로 보이게 했습니다.

## 실행 방법

1. MySQL에 DB를 만들고 `project/onbank/src/main/resources/db/`의 DDL을 **01 → 03 → 02** 순서로 실행합니다. (02가 03의 테이블을 참조합니다)
2. `application-local.properties.example`을 복사해 `application-local.properties`를 만들고 DB 접속 정보를 입력합니다.
3. 실행합니다.
   ```bash
   cd project/onbank
   ./gradlew bootRun
   ```
4. 브라우저에서 http://localhost 로 접속합니다. (포트 80)

## 폴더 구조 (계좌 파트)

```
project/onbank/src/main/java/org/doit/onbank/account/
├── controller/   계좌·이체·즐겨찾기·예약이체·자산 리포트 화면
├── service/      입출금·이체·계좌 개설·예약이체 실행·자산 집계
├── entity/       Account, ScheduledTransfer 등 (상태 변경 규칙을 엔티티 메서드로)
├── repository/   Spring Data JPA, 집계 조회
├── scheduler/    예약·정기이체 스케줄러 (매분 실행)
└── dto/          화면 입력·출력 객체
```
